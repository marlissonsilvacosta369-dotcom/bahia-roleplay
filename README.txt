BAHIA ROLEPLAY WEBSITE - NETLIFY
=================================

Arquivos:
- index.html: estrutura e conteúdo do site
- style.css: identidade visual e responsividade
- script.js: navegação, busca básica e modais

PUBLICAR NO NETLIFY:
1. Extraia o ZIP.
2. Acesse https://app.netlify.com/drop
3. Arraste a pasta "bahia_roleplay_site" (ou os arquivos de dentro dela) para a área de deploy.
4. Após publicar, abra o link gerado pelo Netlify.

PERSONALIZAR ANTES DE PUBLICAR:
- Abra script.js e substitua COLOQUE-SEU-LINK pelo convite do Discord.
- Edite os textos e documentos de demonstração em index.html.
- Atualize produtos, preços, imagens e links de pagamento. A loja está visualmente pronta, mas não processa pagamentos.
- Atualize o texto de status e notícias para dados reais do servidor.

A loja não tem integração de pagamentos e o status de servidor é demonstrativo neste pacote.
