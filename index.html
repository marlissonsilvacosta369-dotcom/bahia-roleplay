CENTRAL DA COMUNIDADE

Denúncias

Registre uma denúncia para a equipe analisar. Preencha as informações com clareza e anexe os detalhes relevantes.

Por enquanto, os registros são salvos neste navegador. O envio para a equipe e armazenamento central será ativado quando o login Discord e o banco de dados forem conectados.
REAVALIAÇÃO DE PUNIÇÕES

Revisões

Solicite a revisão de uma punição aplicada no servidor. Explique seu caso e forneça os dados para análise.

Solicitações demonstrativas: ficam salvas localmente neste navegador até a integração de contas e banco de dados.
ACESSO À CIDADE

Solicitar liberação de ID

Informe seu ID inicial de jogador e o nome e sobrenome RP que deseja registrar. Após a solicitação, o sistema tentará liberar o ID automaticamente no servidor.

A liberação exige login Discord. Informe o ID de usuário que aparece na primeira tentativa de conexão ao servidor e seu nome RP.
STAFF • ACESSO RESTRITO

Painel administrativo

Gerencie denúncias, revisões e liberações de ID. Esta área só aparece para Discord IDs autorizados no backend.

Faça login como administrador para carregar os registros.
